## Trace Filename and Format
Each trace is named `Chip#_WG#.txt`. The dataset identity is carried by the enclosing folder and `metadata.json`.

Every trace is preserved byte-for-byte from its source file. The files are headerless, tab-delimited, two-column text traces:
1. wavelength in nm
2. optical power in W

The filename manifest records the original filename, short trace filename, chip, route, and SHA-256 checksum.
