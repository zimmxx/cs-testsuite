# MPW46 Slot5 Waveguide Manual Raw Data

This folder contains GitHub-hosted measurement traces for MPW46.

## Dataset Summary
- Project: MPW46
- Wafer: Slot5
- Measurement mode: Manual converted
- Source type: Automated WST trace set
- Date: 2026-07-31
- Files: 48
- Chips: Chip3, Chip37, Chip40, Chip46, Chip49, Chip52, Chip61, Chip64
- Waveguides: WG1, WG2, WG3, WG4, WG5, WG6
- Waveguide config: waveguide-config.json
- Normalized rows: 912048
- Wavelength span: 1525.000 nm to 1620.000 nm

## Filename Pattern
Each trace is saved as a two-column text file:
1. wavelength in nm
2. optical power in W

This folder was prepared for the Wafer Post-Processing Suite GitHub measurement-data library.
