# Changelog
# Version: v0.2.1

## Added

- editable output filenames in the `Manual Conversion` results table
- filename overrides that carry through to individual downloads, ZIP exports, and manifest exports

## Changed

- updated the latest documentation references to point to `v0.2.1`
- documented the latest manual-conversion workflow improvements in the project history and release notes

## Fixed

- fixed manual-conversion waveguide detection so `RIB` folders no longer fall back to strip-style output names
- prevented folder names such as `SLOT7` from being mistaken for the waveguide-family token during manual conversion

## Documentation

- added release notes for `v0.2.1`
- updated top-level documentation links to the newest release notes
